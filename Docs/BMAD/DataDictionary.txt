# Từ điển Dữ liệu (Data Dictionary) Hệ thống bao gồm hai nhóm dữ liệu chính: Master Data và Transaction Data. Lược đồ được sinh ra tự động theo mô hình EF Core DB-First. ## 1. Master Data (Dữ liệu Danh mục) - **ProductGroup (Nhóm sản phẩm)** - Quản lý nhóm món ăn (liên kết qua `GroupCode`). - **Product (Sản phẩm)** - Danh sách Menu Item chi tiết. - Có các cột đặc thù: `Unit` (Đơn vị tính), `Cosprice` (Giá vốn), `SellingPrice` (Giá bán). - **StoreGroup (Nhóm cửa hàng)** - Lưu cấu trúc phân nhóm các cửa hàng. - **Store (Cửa hàng)** - Danh mục các nhà hàng (liên kết qua `StoreCode`). - Bao gồm cấu hình để làm gốc tính toán: `NumOfTables` (Tổng số bàn), `MinMenuSelling` (Mức doanh số sàn), `MinSalesContribution` (Mức đóng góp sàn). ## 2. Transaction Data (Dữ liệu Giao dịch) - **MonthlySaleHeader** - Quản lý định danh báo cáo: `StoreCode`, `Year`, `Month`. - Cột tham số chung tự nhập: `Tc` (Transaction count - Số lượng khách/bill). - Cột sao chép/tổng hợp: `Tables` (từ Store), `Sales`, `Cos`, `TotalMargin`. - **MonthlySale** - Chi tiết từng món bán ra theo header. - Thông tin gốc (Copy từ Master Data): `ProductCode`, `ProductName`, `Unit`, `GroupCode`, `Cosprice`, `SellingPrice`. - Kết quả bán thực tế: `SoldQuantity`, `Margin`. - Chỉ số phân tích chuyên sâu (Calculated fields): `CosPercentage`, `SaleMixPercentage`, `MarginMixPercentage`, `ProductMixPercentage`, `TcTable`, `Per100Tc`, `Per100Quality`, `Per100Selling`. - Phân loại Menu Mix: `Popularity`, `Profitability`, `ItemClass` (Star, Plowhorse, Puzzle, Dog). ## 3. Cấu trúc Base Entity / Audit Fields Tất cả các bảng đều được chuẩn hóa với các trường Audit cơ bản: - `CreatedBy`, `CreatedOn` - `ModifiedBy`, `ModifiedOn` - Trạng thái soft-delete: `IsDeleted`, `IsActive`
